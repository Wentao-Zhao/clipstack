# A5 历史面板实现计划

**目标：** 将用户确认的 A5 静态稿落地为原生 AppKit 面板，保留现有搜索、粘贴、图片置顶和四边呼出行为。

**架构：** 控制器负责筛选、焦点与选择；独立的 Shelf 视图负责工具栏、页码和主题；Note 视图负责纸页选中态与图片、文字、链接、代码的排版。内容分类仅用于展示，不改变存储格式或原始复制内容。

**技术栈：** Swift Package、AppKit、Core Animation、现有逻辑测试执行器。

- [x] 为类别与搜索组合、URL/代码/文本呈现添加失败测试，再实现 Core 中的纯展示模型及筛选参数。
- [x] 将旧的彩色便签与渐变外框替换为 A5：深色内容条、白色选中项、少量钴蓝、按内容排版、紧凑顶部与底部。按后续反馈去掉选中项背后叠层，不放大、不使用卡片阴影。保留浅色模式，并适配顶部、底部、左侧和右侧。
- [x] 接入真实「全部/文本/图片」筛选、数量与选中位置、偏好设置按钮。选择后动作提示随配置显示粘贴或复制。
- [x] 运行逻辑测试与发布构建；用真实 AppKit 面板在隔离数据目录渲染深色/浅色/侧栏/空状态，验证搜索、筛选、键盘选择、图片置顶与激活。
- [x] 生成 `dist/ClipStack.app`，检查改动与产物，更新使用说明和设计记录。

**边界：** 不引入云同步、网站元数据抓取或新持久化字段；链接与代码分类采用保守的本地文本判断。预览验证使用临时数据目录，不读写用户已有历史或系统剪贴板。

验证结果：逻辑测试 `PASS: 112 checks`；`zsh scripts/verify-panel.sh` 的真实原生交互检查通过，并核对 `output/panel-preview/` 下的深浅色和空状态截图。缩略图由 ImageIO 降采样到最长边 480 像素，已验证旧小缩略图的按需更新。独立审查指出的 VoiceOver 正文缺失已补充，后续审查无新增问题。

构建环境：当前受限环境中的 SwiftPM 默认 swiftbuild 在生成 dSYM 时被系统拒绝，使用 `--build-system native --disable-sandbox` 完成构建；打包命令为 `CLIPBOARD_HISTORY_BUILD_SYSTEM=native CLIPBOARD_HISTORY_SWIFTPM_DISABLE_SANDBOX=1 zsh scripts/package-app.sh`。该构建系统选择仅为显式参数，不改变脚本默认行为。
