# 历史面板焦点优化设计

## 目标

ClipStack 呼出历史面板后统一聚焦历史便签区。用户无需先点搜索框，直接输入普通文字即可进入搜索；搜索内容清空后自动回到便签区。

## 交互规则

- 面板呼出后，便签区成为第一响应者，第一条可用历史保持选中。
- 便签区收到普通文字输入时，先切换到搜索框，再把当前按键交给搜索框处理，首个字符不能丢失。
- `Command`、`Control` 快捷键、方向键、回车、Escape、删除键等控制输入不触发自动搜索。
- 搜索框查询从非空变为空时，自动将焦点切回便签区。
- 搜索框按向下方向键进入便签区；便签区按向上方向键进入搜索框，原有左右/上下选择能力保持不变。
- 偏好设置中的“呼出后聚焦搜索”配置及底层配置字段移除。旧版 UserDefaults 中遗留的键不再读取，不影响升级。

## 实现边界

在 `ClipboardHistoryCore` 中新增纯逻辑输入路由，负责判断键盘输入是否应启动搜索，避免把 AppKit 事件判断散落在视图中。`HistoryPanelController` 只负责切换第一响应者、转发事件和在搜索清空时恢复焦点。

## 验证

- 逻辑测试覆盖普通字符、带 Shift 字符、方向键、删除键及 Command/Control 组合键。
- 配置测试确认默认配置不再包含搜索初始焦点选项。
- 完整逻辑测试与 Release 构建通过。
