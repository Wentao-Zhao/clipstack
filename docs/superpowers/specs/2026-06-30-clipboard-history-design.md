# 剪贴板历史设计说明

## 背景

本项目是一个 macOS 菜单栏 App，用于保留文本和图片剪贴板历史。它不改变系统默认复制、粘贴行为，用户仍然正常使用 `Command+C` 和 `Command+V`。历史面板通过双击 `Command` 呼出，选中历史项后自动粘贴到当前 App。

项目目录为 `/Users/wentaozhao/code/aiCode/codeX/myMacApp/ClipboardHistory`，与现有 `ScreenCleaner` 项目同级，互不影响。

## 目标

- 后台记录系统剪贴板中的纯文本和图片。
- 双击 `Command` 呼出历史剪贴板列表。
- 选中历史项后自动粘贴到当前 App。
- 支持可配置的保留时间、数量限制、单条大小限制和内存预算。
- 内容落盘保存，App 退出或电脑重启后仍可按保留时间恢复。
- 默认控制内存占用，列表只展示文本预览和图片缩略图。

## 非目标

- 不记录文件、视频、复杂富文本样式。
- 不做云同步。
- 不做加密。
- 不替换系统原生剪贴板，不拦截正常复制和粘贴。
- 第一版不做全文搜索、标签、收藏和多设备同步。

## App 形态

- App 显示名：`剪贴板历史`。
- Bundle 名称：`ClipboardHistory`。
- Bundle ID：`com.local.ClipboardHistory`。
- macOS 版本：macOS 13 及以上。
- 形态：菜单栏 App，`LSUIElement` 为 `true`，无 Dock 图标、无主窗口。
- 菜单栏右键菜单：
  - `打开历史剪贴板`
  - `偏好设置`
  - `清空历史`
  - `退出 App`

## 核心交互

### 记录历史

App 定时轮询 `NSPasteboard.general.changeCount`。当 changeCount 变化时，读取当前剪贴板：

1. 如果存在纯文本，按 UTF-8 字节数检查大小，未超过上限则保存。
2. 如果存在图片，优先读取图片数据并生成缩略图，未超过上限则保存。
3. 文件、视频和其他复杂类型不记录。
4. 与最近一条记录内容相同的数据不重复记录。

### 呼出历史面板

双击 `Command` 触发历史面板。识别规则：

- 只识别单独按下并释放 `Command` 两次。
- 两次敲击之间的间隔默认不超过 `350 ms`。
- 如果期间出现普通按键，或存在非 `Command` 修饰键，则取消本次双击识别。
- `Command+C`、`Command+V`、`Command+Tab` 等组合键不触发。

### 自动粘贴

用户在历史面板中选择一条记录后：

1. 将该记录内容写入系统剪贴板。
2. 刷新该记录的 `lastUsedAt`。
3. 模拟 `Command+V`，粘贴到当前前台 App。
4. 关闭历史面板。

记录剪贴板不需要辅助功能权限。双击 `Command` 全局监听和模拟粘贴需要辅助功能权限。如果权限未开启，App 仍可记录历史；选择历史项时只复制回系统剪贴板，并提示用户开启权限后可自动粘贴。

## 存储设计

内容不加密，保存在当前用户的 Application Support 目录：

```text
~/Library/Application Support/ClipboardHistory/
  index.json
  items/
    <uuid>.txt
    <uuid>.png
  thumbnails/
    <uuid>.png
```

`index.json` 只保存元数据：

- `id`
- `kind`：`text` 或 `image`
- `createdAt`
- `lastUsedAt`
- `byteSize`
- `preview`：文本前 500 个字符；图片为空字符串
- `contentRelativePath`
- `thumbnailRelativePath`

内存中只长期保留元数据、文本预览和少量图片缩略图缓存。真实文本和图片内容在粘贴时从磁盘读取。

## 默认配置

- 保留时间：默认 `6 小时`
- 可选保留时间：`15 分钟`、`1 小时`、`3 小时`、`6 小时`、`12 小时`、`24 小时`、`7 天`、`30 天`
- 文本最多：默认 `100 条`
- 图片最多：默认 `10 张`
- 单条文本上限：默认 `4 MB`
- 单张图片上限：默认 `5 MB`
- 内存预算：默认 `32 MB`
- 内存清理触发点：超过预算的 `90%`
- 内存清理目标：降到预算的 `60%`
- 退出 App 时清空历史：默认关闭

超过单条大小限制的文本或图片直接丢弃，不写入磁盘，也不进入列表。

## 清理和驱逐

清理分为三类：

1. **过期清理：** 根据保留时间删除过期记录和对应文件。
2. **数量清理：** 文本和图片分别按配置数量上限保留，超出时按 `lastUsedAt` 从旧到新删除。
3. **内存缓存清理：** 当缩略图和最近内容缓存估算值超过内存预算的 `90%` 时，按 `lastUsedAt` 从旧到新驱逐缓存，直到降到预算的 `60%`。

用户粘贴一次历史项后，该记录的 `lastUsedAt` 刷新，因此更不容易被数量清理和缓存清理驱逐。

## UI 设计

### 历史面板

- 使用轻量 `NSPanel`。
- 呼出时显示在当前屏幕中央。
- 列表按 `lastUsedAt` 倒序展示。
- 文本记录展示前 `500` 个字符。
- 图片记录只展示缩略图和基础信息。
- 点击或按 Enter 选择当前项并粘贴。
- 按 Escape 关闭。

### 偏好设置

偏好设置窗口提供：

- 保留时间选择。
- 文本数量上限。
- 图片数量上限。
- 单条文本大小上限。
- 单张图片大小上限。
- 内存预算。
- 退出 App 时清空历史开关。

配置保存到 `UserDefaults`，下次启动生效。

## 架构

项目采用 Swift Package：

- `ClipboardHistoryCore`：纯 Swift 逻辑，负责配置、捕获策略、预览、驱逐策略、双击 `Command` 状态机和元数据模型。
- `ClipboardHistory`：AppKit 集成，负责菜单栏、剪贴板轮询、磁盘存储、历史面板、偏好设置、权限和自动粘贴。
- `ClipboardHistoryLogicTests`：轻量测试 runner，覆盖核心策略。
